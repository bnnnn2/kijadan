# 사진 배분 도구

폴더 안의 사진을 글 개수만큼 겹치지 않게 나눠 담는 웹 도구입니다.

주소: https://bnnnn2.github.io/kijadan/

## 특징

- 설치 없이 브라우저에서 바로 사용합니다.
- **사진은 서버로 전송되지 않습니다.** 파일 읽기·쓰기가 전부 브라우저 안에서 일어납니다.
- PC의 크롬 또는 엣지에서만 동작합니다(폴더 접근 기능 미지원 브라우저는 안내 문구를 표시).

## 배분 방식 두 가지

- **일반 배분** — 글당 최소 장수를 정하면 글마다 +1~3장씩 변주해 나눕니다.
- **전 / 후 배분** — 폴더마다 [전] / [후] / [사용 안 함] 을 지정하고, 글당 전·후 최소 장수를 각각 정합니다.
  글마다 +0~2장씩 변주되며, 한 글 폴더 안에서 번호는 전 사진이 먼저, 이어서 후 사진입니다.

## 사용법

1. 사진 폴더들이 들어 있는 상위 폴더를 고릅니다.
2. 배분 방식과 글 수·최소 장수를 정합니다(전/후 배분이면 폴더별 역할도 지정).
3. 실행하면 `발행/01`, `발행/02` … 폴더에 `1.jpeg`, `2.jpeg` … 로 나뉘어 저장되고, 쓴 사진은 원본 폴더에서 사라집니다.

사진이 모자라면 아무것도 옮기지 않고 부족한 장수만 알려 줍니다(전/후는 각각 따로 확인).
옮긴 내역은 `발행/_배분기록.txt` 에 원본 경로와 전/후 구분까지 남습니다.

원고는 이 도구가 만들지 않습니다. 사진만 나눕니다.
